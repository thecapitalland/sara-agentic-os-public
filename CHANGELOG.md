# Changelog

## 2.0.0 — 2026-10-06

Sara becomes a unified Agentic Engineering Operating System.

### Added
- four-plane architecture: Governance & Delivery, Context & Cognition, Runtime & Capability, Evidence & Assurance;
- canonical machine-readable manifest;
- 12 bounded specialist Agent contracts;
- 16 reusable Skill contracts;
- Objective, Work Item, Outcome, State, Gates, and Result templates;
- task-conditioned context and memory boundaries;
- Experience and Outcome learning contracts;
- exact-candidate evidence and independent-review rules;
- rollback and recovery discipline;
- minimal v2 adoption example;
- baseline validator.

### Changed
- public license changed to MIT;
- public documentation is model- and vendor-agnostic;
- one canonical document owns each policy concern;
- orchestration is smallest-sufficient instead of roster-wide;
- stable version facts are centralized in the manifest.

### Removed
- legacy public authority;
- product-specific adapter documentation;
- named third-party integration documentation;
- internal lineage and private-repository history;
- duplicate or stale operating-model documents.
