# Roadmap

Sara v2 is stable as a public governance/runtime contract baseline.

Future work is evidence-gated.

## Adoption quality
Measure objective-to-review time, human relay events, first-pass acceptance, rework, unnecessary Agent invocation, context volume, escaped defects, and rollback readiness.

## Runtime packaging
Build deterministic install/render tooling only when repeated manual installation becomes real friction. It must be dry-run-first, manifest-driven, reversible, and avoid credential mutation.

## Context optimization
Benchmark generic context providers against ordinary repository discovery. Keep providers optional unless evidence justifies a stronger default.

## Experience & learning
Start with Experience and Outcome records. Do not enable autonomous memory promotion or self-modifying policy until evidence, evaluation, and rollback are strong.

## Interoperability
Keep contracts portable across reasoning engines and execution clients without creating competing canonical definitions.

Non-goals: agent proliferation, mandatory centralized service, mandatory hosted control plane, autonomous memory as a prerequisite, production auto-release by default, and self-approval of material changes.
