# Document Registry

This registry prevents multiple documents from silently owning the same rule.

| Subject | Canonical owner |
| --- | --- |
| machine-readable system/roster facts | `sara/manifest.json` |
| agent bootstrap/load order | `AGENTS.md` |
| unified architecture | `docs/ARCHITECTURE.md` |
| project/work lifecycle | `docs/OPERATING_MODEL_V1.md` |
| Agent/Skill semantics and routing | `docs/RUNTIME_MODEL.md` + `runtime/` |
| context-provider contract | `docs/CONTEXT_ENGINE.md` |
| evidence/review/publish/rollback | `docs/EVIDENCE_ASSURANCE.md` |
| cognitive/learning research direction | `docs/COGNITIVE_ARCHITECTURE.md` |
| lineage/migration rationale | `docs/MIGRATION_AND_LINEAGE.md` |

Older v0 documents are retained for history/adoption context. When they conflict with the v1 owners above, v1 controls.
