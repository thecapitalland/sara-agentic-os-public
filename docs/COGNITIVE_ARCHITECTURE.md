# Cognitive Architecture

Sara treats cognition as engineering functions, not as a claim to simulate a human brain.

Shared functions:
- Perception — code, diffs, events, outputs, repository state.
- Attention — choose what deserves context and reasoning budget.
- Memory — working, episodic, and carefully promoted durable facts.
- Value & Risk — confidence, consequence, novelty, acceptance quality.
- Action — bounded edits, tools, commands, and external changes.

```text
observations
   ↓
selective context / gating
   ↓
typed shared task state
   ↓
specialist capability
   ↓
actions
   ↓
outcomes
   ↓
experience / learning candidates
```

Before learning, record what happened. Learning may make no change, retain episodic evidence, promote a verified fact, adjust retrieval/routing preference, decay a weak path, create a Skill candidate, or add a regression fixture.

One successful run never becomes universal law automatically.
